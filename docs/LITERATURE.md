# ОБЗОР ЛИТЕРАТУРЫ: «корпусный приор улучшает нейросетевую LM в её домене»

Дата: 2026-08-14. Контекст: эксперимент AC показал, что микстура
P = (1−β)·P_model + β·P_corpus улучшает PPL и accuracy на настоящей
LLM даже в «родном» домене (Python: PPL 7.9 → 4.0). Вопрос: известно
ли это? Ответ: ДА — эффект известен под четырьмя именами, это не
новизна. Ниже — карта известного, чтобы больше не переоткрывать.

---

## 1. Jelinek–Mercer smoothing (1980) — сама микстура

F. Jelinek, R. Mercer. «Interpolated estimation of Markov source
parameters from sparse data». Классика n-граммных LM: сглаживание
линейной интерполяцией P = λ·P_n-gram + (1−λ)·P_shorter. Наш AB —
буквально Jelinek–Mercer, где «короткая» модель заменена нейросетью.
Известно 45 лет.

## 2. Cache LM (Grave, Joulin, Cissé, 2017) — наш recency-слой

«Improving Neural Language Models with a Continuous Cache» (ICLR 2017).
Интерполяция нейросети с кэшем НЕДАВНИХ скрытых состояний. Снижает PPL
даже для сильных моделей. Это ровно наш Z-слой «recency» — единственный
ортогональный сигнал, который мы нашли. Известно 9 лет.

## 3. kNN-LM (Khandelwal et al., ICLR 2020) — наш корпусный приор

«Generalization through Memorization: Nearest Neighbor Language Models».
Интерполяция нейросети с k-ближайшими соседями по эмбеддингам из
ОГРОМНОГО корпуса (3 млрд токенов). Улучшает PPL драматически (например,
~2.9 пункта на Wikitext-103 поверх сильной модели). Наш Morin-приор —
частный случай kNN-LM, где соседи берутся n-граммным совпадением, а не
эмбеддинговым расстоянием. Известно 6 лет.

Сопутствующее:
- «Why do Nearest Neighbor Language Models Work?» (2023) — разбор механизма.
- «KNN-LM Does Not Improve Open-ended Text Generation» (2023) — ограничение:
  выигрыш PPL не всегда переносится на генерацию (наш AC мерял PPL — та же ловушка).
- «Nearest Neighbor Speculative Decoding» (2024) — kNN + speculative decoding.
- «Efficient Nearest Neighbor Language Models» (EMNLP 2021) — ускорение kNN-LM.
- «Adaptation Approaches for Nearest Neighbor Language Models» (2023) — доменная адаптация.

## 4. Induction Heads Interpolate N-Grams (arXiv, июль 2026)

Свежайшая работа: трансформеры интернируют n-граммные распределения
внутри attention-механизма. Это теоретическое объяснение, ПОЧЕМУ наш
эффект работает: корпусный приор дублирует то, что модель уже частично
умеет — но добавляет недостающую локальную статистику.

## ВЕРДИКТ

**Наша «заявка на новизну» (AC) закрыта обзором: эффект известен.**
Цепочка: микстура = Jelinek–Mercer (1980); recency = Cache LM (2017);
корпусный приор = kNN-LM (2020). Мы переоткрыли kNN-LM в упрощённой
n-граммной форме на код-домене.

**Что из этого следует (честно):**

1. Урок «обзор ДО экспериментов» сработал: вместо недели заявок на
   новизну — один вечер проверки, эффект классифицирован.
2. Наша работа — НЕ новизна, но и НЕ ноль: измерен конкретный случай
   (n-граммный приор вместо эмбеддингового kNN на 102K-словарной
   код-модели, CPU), с честной историей всех ошибок. Инженерная
   ценность — дешёвая замена kNN-LM без эмбеддингового индекса.
3. Единственный потенциально интересный угол, который известная
   литература НЕ закрывает: наш приор дешевле kNN-LM на порядки
   (n-граммная таблица против миллиардного эмбеддингового индекса).
   Если это подтвердить сравнением «n-gram prior vs kNN-LM при равном
   бюджете памяти» — это маленькая, но честная инженерная публикация.

**Решение по плану «прорыв»:** научная дорожка закрыта (эффект известен).
Остаётся продуктовая дорожка: дешёвый корпусный приор для локальных
моделей (llama.cpp/Ollama) — плюс сравнение с kNN-LM по цене/качеству.
